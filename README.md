# Bloomkeeper 🌱

A cozy 3D garden game for the mobile web. Help Granny Rose grow veggies, catch the harvest, pay the bills, and keep the crows (and the Crow King!) away from Spring Garden.

**Play:** https://kormocicsaba.github.io/bloomkeeper-web/ (best on a phone, in portrait)

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Built with

Three.js, TypeScript and Vite. Pushing to `main` deploys to GitHub Pages automatically.
